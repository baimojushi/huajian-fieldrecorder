# 画间 v1.3 · 真机与云端接口验收清单

> **全部标记为待测**。离线通过的单元/文件结构测试不能替代 Android 编译或本清单。先用有许可的非儿童音频和两名自愿成人测试，儿童绘画测试必须放在技术验收之后。

## A. Android 本机稳定性

- [ ] Android 8 / Android 13+ 至少两款设备完成 APK 安装、CameraX 权限请求、HD 录像（含声音）、回看。
- [ ] 原生录像/系统相机/相册导入三个入口保存的音频可完整解码。
- [ ] 录像期间短按九类事件与长按备注不影响原始 MP4。
- [ ] 录制 1 / 5 / 30 分钟、屏幕亮灭/来电/存储不足/断电与权限撤销具有清晰错误路径。
- [ ] Android Keystore 保存 Key、重启/强杀后可识别、删除后拒绝识别；key 不进入日志/ZIP。
- [ ] 无 Key、无网络或未勾选云端同意时仍可录像与本地分包。

## B. DashScope Qwen3 真实接口

- [ ] Key 北京与新加坡地域分别测试（只使用有权限的环境），WebSocket TLS 成功。
- [ ] `session.update` 被服务端确认，PCM16 16k 单声道按 100 ms 块送入。
- [ ] 收到 `input_audio_buffer.speech_started/stopped` 和 `conversation.item.input_audio_transcription.completed`；`item_id` 关联一致。
- [ ] 从最终完成事件提取真实 `transcript`、`emotion`；不臆造置信度或字级时间。
- [ ] 44 秒既有非儿童样本：人工核听语句，对比误识别和背景设备音幻觉；无内容段不应凭空生成完整发言。
- [ ] 所有语音句段起止时间与原 MP4 回看对应；开头 15ms 音轨偏移有正确补偿；分包后时间轴不漂移。
- [ ] 断网、过期 Key、无权限、计费额度不足、服务端返回错误、最终未响应时：显示失败且**不导出 completed 假结果**。
- [ ] 重复请求提示可能再次计费；录制和原音轨始终保持完整。

## C. 多人声纹与真实情绪标签限制

- [ ] 用两名成年人的已知台词、不同距离、交替讲话、短暂重叠讲话独立生成声纹 JSON。
- [ ] 手机导入本地离线声纹文件，核对 S1/S2 的时间交叠与原视频音轨，低置信度/重叠标 unknown。
- [ ] 无法把 S1 自动推断为儿童，不能根据情绪标签强制归属说话人。
- [ ] 对七类情绪只认作模型声学标签；人工核验无可靠后验置信度，不生成虚假百分比。
- [ ] 说明本版**不包含手机端 sherpa-onnx 模型推理**，仅有离线声纹 JSON 导入/融合。

## D. 导出与 GPT 上传

- [ ] M4A 对比源 AAC 编码包及其音频 PTS，抽帧请求时间与全局时间轴可复核。
- [ ] 分包后无缺包和哈希不一致； `*_PACKET_INDEX.json` 位于 ZIP 外，完整性校验通过。
- [ ] 大于 400MB 的输入自动生成多个 ZIP，所有 ZIP <400,000,000 字节；完整覆盖全部媒体。
- [ ] `SPEECH/` 仅在成功 ASR 时有 Qwen3 内容，人工声纹文件仅在成功融合时导出。
- [ ] 解压本地 viewer 能跳转语句与画面；从音频第一帧15ms起播不静音卡死。
- [ ] GPT-6 平台实际读取逐段音频/抽帧/JSON，而不是只读 ZIP 文件名。
