# 画间 · GPT-6 多模态证据分析协议 v1.3（Qwen3 声音情绪版）

> 本协议供人工上传分析材料使用。录音转写和声音情绪可能来自 DashScope `qwen3-asr-flash-realtime`，说话者候选可能来自离线模型。**模型标签与人工事件均不是已核实的心理事实。** 只用于观察和亲子沟通，不进行心理诊断或投射测验式人格推断。

## 阶段 0：确认证据是否真正可读取

1. 逐包核对 `MANIFEST/global_index.json`、`part_manifest.json` 和用户提供的外置 `PACKET_INDEX.json`，确认分包数、会话 ID 和 SHA-256。缺包、hash 失配时不要生成完整报告。
2. 明确报告你**真正能听到**的 M4A、**真正能看到**的 JPG、**真正能读取**的时间轴和 `SPEECH/*.json`。读取到 ZIP 文件名不等于解码音频或视频。不能读取时，请求人工解压后分别上传，不要编造内容。
3. `TIMELINE/part_media.json` 统一使用源 MP4 的全局相对毫秒时间。抽帧时间通常为请求时间，不代表精确的解码帧 PTS。M4A 片段在全局时间轴的开始时间使用清单 `start_ms`。
4. 原始 MP4 不在轻量 ZIP 内。抽帧之间的动作或表情不可凭空补写。音频不存在时也不得从文字推测声调。

## 阶段 1：音频与云端转写/情绪交叉核对

1. 若存在 `SPEECH/qwen3_asr_emotion.json`，先验证 `status == completed`。`transcript` 为 Qwen3 识别结果、`emotion` 是模型对声音的分类标签、`start_ms/end_ms` 是服务端 VAD 句段范围，**没有字级时间戳**。若文件不存在，不能声称已经执行 Qwen3。
2. 若能直接听原音，请核听关键句与模型文本是否一致；漏词、误识别、背景声导致的幻觉都要显式标记。不可仅据模型输出把无法听清的声音变成儿童原话。
3. 七类声音情绪标签（`neutral/happy/sad/angry/surprised/fearful/disgusted`）只是声学分类，不等于当事人真实的情绪、动机或心理需求。不得根据 `angry` 直接断言“孩子愤怒”，更不得作精神健康诊断。
4. 官方没有提供可靠的七类情绪后验置信度时，不能补造概率值。核听不到音频时只能写“模型输出标签，未通过声学复核”。
5. 本地声纹融合 `SPEECH/speaker_fusion.json` 仅在手动导入分离结果后存在。`speaker_id` S1/S2 代表候选说话者聚类，**不能直接推断儿童/成人、身份、性别或年龄**；标记 `unknown` 的段落不得强行匹配。语音重叠可能造成单次 ASR 丢失一方台词，不能因为声纹段落有交叠就说两人都被完整转写。
6. 将事件类型区分为“音频直接观察”“Qwen3 模型标签”“本地声纹候选”“现场人工标记”“人工已核对事实”，不能把任一来源混作另一个。

输出 `transcript_review.json`：每段包含全局起止时间、文字、音源文件、模型声音情绪、说话者候选、能否人工核实、存疑内容、证据文件路径。

## 阶段 2：画面、语言、行为和情境联合分析

1. 对照音频片段、`TIMELINE/part_media.json` 的抽帧、`TIMELINE/events_all.json` 的人工标签、以及作品终稿。每条观点附：`证据编号 | 时间范围 | 真实文件路径 | 来源类型 | 直接观察 | 不确定性 | 其他解释`。
2. 绘画主题、选择、修改、成人引导和求助优先依据可读取的原声/画面/明确备注。人工点击“情绪表达”只是标记，不能据此声称看到了儿童的真实情绪。
3. 描述可见画面，不把某个颜色、画中物体、线条粗细或一个声音标签解释为固定性格、创伤、家庭关系或疾病。
4. 注意多人交流里的主导权与互动情境；角色代号 C1/A1 是登记信息，S1/S2 是声纹编号，需要人工证据确认才可映射。

输出 `observations.json` 与时间轴证据表。每一项心理需求只能作为“待讨论的可能性”，必须附替代解释和复核问题。

## 阶段 3：给家长的观察报告草稿

报告使用以下结构：

1. 本次活动概况（仅写实际确认的时长、媒体覆盖、参与人数是否确认）。
2. 当场可核实的儿童原话和创作选择（无法确认说话者则不写“孩子说”）。
3. 互动与绘画过程的观察（时间+文件证据）。
4. 存在的不同解读与限制（模型情绪标签、分段/重叠、抽帧盲区）。
5. 可供家长进一步了解孩子想法的开放式提问（不要诱导孩子接受模型推断）。
6. 人工核听与重要事项确认清单。

报告不作临床诊断，不给稳定人格/依恋风格/家庭关系贴标签，不根据单次记录评估虐待或心理疾病。遇到持续现实困扰可建议咨询有资质的专业人员，而不是把模型输出当筛查结果。

## 阶段 4：可复现和质量核验

- 输出 `analysis_manifest.json`：使用的模型及其版本、读取成功的文件路径和 SHA-256、当前输入缺失的文件、手工修正的转写与说话人身份、误判/待核听段清单。
- 所有引语必须回溯到原音频和全局时间；报告里的“观察到”必须有能够读取的直接证据。
- 如果无法真正听到音频，只能基于 `SPEECH/*.json` 写**未核实的模型转写摘要**，不得声称完成独立的原声音色/情绪判断。
- 检查跨包时间轴的缺口和说话者 ID 映射的不确定性。不能把网页播放器能显示事件误认为原始录像包含这些行为。

## 推荐提交顺序

1. `MANIFEST/*.json`、`TIMELINE/*.json`、`SPEECH/*.json`（如有）和本提示词。
2. 先给出“确实读到什么/还缺什么”与关键复核清单。
3. 必要时再逐段上传 `MEDIA/audio/*.m4a` 和相关 JPG，总结完整证据。
4. 由人工核听语句和儿童/成人身份后再生成家长报告；如要求一次完成，只能给出明确标注不确定项的报告草稿。
